# 베이스 실기 연습실

실용음악과 베이스 실기(한양대 ERICA, 서울예대, 동아방송예대, 호원대, 홍익대) 대비 연습 앱이에요.

- 즉흥 코드 문제, 피아노와 드럼 반주, 모범 베이스 라인
- 리듬 초견과 낮은음자리표 음 초견, 마이크 채점(실험)
- 실용음악통론 퀴즈, 청음, 면접 예상 질문
- 자유곡 타이머, 튜너, 녹음, 연습 기록, 실전 모의고사

시험 구성 정보는 공식 요강과 학원 정리 자료를 모은 것이라, 지원 전에 각 학교 입학처의 2027학년도 요강 원문을 꼭 확인하세요.
녹음과 연습 기록은 사용하는 기기의 브라우저에만 저장돼요.
